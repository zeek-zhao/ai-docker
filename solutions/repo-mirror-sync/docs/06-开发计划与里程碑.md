## 5 推进规则

1. 严格 BDD 顺序：场景→红灯→实现→绿灯→治理同步→提交（docs/05 §4）；
2. 每个里程碑一个提交主题，提交说明末尾附 SC/FR 映射；
3. 任何里程碑内发现文档与实现语义冲突：先改文档（重大变更走 docs/04 §6）；
4. 本文档 §4 勾选状态即进度记录，每完成一项勾选并在里程碑完成后提交。
