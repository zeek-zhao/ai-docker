# PL-002 落地计划：M6 CI 构建与验收

> 文档编号：PL-002 · 版本：v1.0 · 日期：2026-11-28 · 作者：zeek.zhao（AI 起草） · 评审：需求方已确认三项决策 · 状态：执行中

## 1. 任务分解

| 任务 | 内容 | 关键点 |
|------|------|--------|
| T6.1 | 新建 `.github/workflows/docker-image.yml` | build-push-action@v6 + GHA 缓存；target=final；双 tag；login 用 GITHUB_TOKEN；CA 兜底目录等效 build.sh |
| T6.2 | 提交 push ai-devbox，轮询 Actions 至成功 | 预计 20–40 分钟（首跑无缓存） |
| T6.3 | 可见性兜底 | 先匿名拉取实测；被拒则本地一次性用密钥 PATCH /user/packages/container/ai-docker 设 public |
| T6.4 | 本地拉取 | docker pull ghcr.io/zeek-zhao/ai-docker:<tag>；失败换国内加速源（如 ghcr.nju.edu.cn） |
| T6.5 | 容器验收 | ①SSH：python3 --user paramiko 口令登录（远程无 sudo 装不了 sshpass）②curl 全路由+鉴权闭环（复用 M5 冒烟方法）③真浏览器 agent-browser 登录后逐一验证服务并截图 |
| T6.6 | 自迭代 | 失败→修复→push→CI→拉取→测试循环 |
| T6.7 | 收尾 | 容器删除；文档收尾；merge main（--no-ff 保身份） |

## 2. 技术决策记录

| # | 决策 | 理由 |
|---|------|------|
| D6 | CI 用 build-push-action 而非复用 build.sh | GHA 缓存（cache-from/to type=gha）使自迭代每次节省约 10–20 分钟；CA 兜底以 mkdir+touch 等效保留 |
| D7 | 可见性「先实测后兜底」 | 需求方认为公开仓库推送即公开；保留匿名拉取实测闭环，避免未经证据的操作或未经验证的假设 |
| D8 | SSH 验收用 paramiko | 构建机无 sudo，sshpass/expect 不可安装；paramiko 纯用户态 pip --user 可装 |

## 3. 风险预告（详 RK-001）

- R12 GHCR 新包可见性与仓库公开性解耦，默认 private；
- R13 Actions 首跑时长与额度（公共仓库免费但排队波动）；
- R14 构建机到 ghcr.io 的网络（备用国内加速源）。
