## 4. 交付物

1. `Dockerfile`：五阶段多阶段构建，成品 COPY 瘦身
2. `docker-compose.yml`：端口 8080 / 2222:22、HOST_UID/GID、devbox 挂载、docker socket 只读参数化
3. `entrypoint.sh`：UID/GID 对齐 → 密码 → age 解密还原 → 目录准备 → 起服务 → 前台守护
4. `config/`：gitconfig、zsh（OMZ+p10k）、vim（LazyVim）、tmux（oh-my-tmux）、caddy（Caddyfile + auth-gate 会话鉴权）、homepage
5. `secrets/`：manifest.json、README.md（私钥不入库）
6. `scripts/`：build.sh、run.sh、age-keygen.sh、encrypt.sh、pack.sh、decrypt.sh、restore.sh
7. `docs/`：ISO 风格过程文档（本系列）
8. 仓库根 `AGENTS.md`：工作流/分支/提交规范（已作为 main 基线提交）

## 5. 硬约束

1. 凭据与提交人信息仅做**仓库局部配置**，禁止 global；提交身份仅 `zeek.zhao` / `zeek.zhao@foxmail.com`（含合并提交）。
2. 临时脚本用完即删，不得留在仓库或工作区。
3. 密钥不进仓库；`secrets/` 只允许密文与清单。
4. 开发使用 RTK 进行上下文压缩。

6. 文档先行、里程碑驱动；问题/方案/AI 操作记录落档。
