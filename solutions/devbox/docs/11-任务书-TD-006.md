## 4. 关键侦察事实（2026-11-28 实测）

- dsh web 实际运行于自动创建的 `~/.dsh/profiles/web`（仅 whale-pet）；desktop 档案为 Electron 专属，web 版不读取。
- desktop 档案 node_modules 为空：23 依赖中 dsh-at-file 的 peer（@deepseek-ai/dsh-client-runtime）拉取私有 rc 包（@deepseek-ai/dsh-compact 等，公共 registry 404）→ pnpm install 全断；原 RUN `pnpm install 2>&1 | tail -3` 管道吞错（exit=tail=0）→ CI 假成功。
- pnpm v12.23.0：`pnpm.onlyBuiltDependencies`（package.json）与 pnpm-workspace.yaml `onlyBuiltDependencies` 均失效（对照实验 A/B/C 均 ERR_PNPM_IGNORED_BUILDS）；仅 `--allow-build=<pkg>` flag 生效（实验 D EXIT=0）。
- 系统网络与证书全通（dev curl api.github.com=200、bun add 成功、magpie 自动更新 6 包成功）——「网络问题」非真实网络故障。
