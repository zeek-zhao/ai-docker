## 1. 背景与目标

M5 已交付本地构建与冒烟全绿的 zeek-ai-devbox 镜像。本任务将构建环节上移至 GitHub Actions（CI），实现 push 自动构建、镜像按构建时刻（Asia/Shanghai，精确到分钟）打日期 tag 且 latest 恒指最新，随后本地拉取该 CI 产物进行验收测试（SSH/网页/认证后功能），不过关则自迭代循环直至全绿。

## 3. 验收标准

1. SSH 口令可正常连接容器；
2. 网页可访问各服务路由（/ /term /file-share，/dsh /magpie 503 门控）；
3. 通过认证登录后各服务功能正常（真浏览器验证并留痕）。
