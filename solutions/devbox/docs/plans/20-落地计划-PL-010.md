## 2. 关键决策

- **D38 版本 auto 化**：探测集中在 services 首个 RUN（/out/versions.env 供后续 RUN source），探测失败一律回退已知稳定版（R20 原则推广到全部组件）；GHA runner 限流用 buildx secrets（gh_token=${{ secrets.GITHUB_TOKEN }}），本地 build.sh 无 secret 匿名探测（本地网络无限流）。
- **D39 .env 机制**：compose 原生 .env 自动加载，模板入库（.gitignore 豁免 `!.env.example`——注意 gitignore 行内注释会使豁免失效），真实 .env 严禁入库。
- **D40 magpie 面板化**：--gateway 是面板功能裁剪开关而非网关必需——实测无 --gateway 时 3425 照常监听；面板完整形态（Agents/Sessions/Library）与 DSH 供给链路兼容。
