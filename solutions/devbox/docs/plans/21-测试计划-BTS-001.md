# BTS-001 —— DevBox Bats 冒烟测试计划（BDD）

> 文档编号：BTS-001 · 版本：v1.0 · 日期：2026-11-29 · 作者：zeek.zhao · 状态：已确认 · 依据：M16 任务书 TD-011 §4（需求方确认：镜像内置 bats）

## 1. 目标

以 Bats（Bash Automated Testing System）BDD 风格自动化验证「镜像声明的能力」真实可用：
软件安装与版本、服务运行/连通/登录、账号密码有效性、动态生成文件（/run/devbox/*）存在且内容真实可用。

## 2. 运行环境与方式

- bats 由镜像内置（Dockerfile toolchain-build `npm install -g bats`，随镜像分发）。
- 测试脚本 `tests/*.bats` 由 `tests/run-tests.sh` 以只读卷挂载进运行容器执行：
  `tests/run-tests.sh`（默认容器名 devbox）≈ `docker exec devbox bats /tests`。
- 断言环境变量（run-tests.sh 注入）：`WEB_PORT`（宿主网页端口，默认 8080）、`SMOKE_HOST`（宿主地址，默认 127.0.0.1）。
- BDD 命名约定：`@test "B<N> Given <前置> When <动作> Then <预期>"`。

## 3. 用例矩阵

### B1 软件安装与版本（Given 镜像内环境 When 查询版本 Then 存在且格式正确）

| 软件 | 断言 |
|---|---|
| node/go/pnpm/bun/dsh | 版本输出非空（node v26+/go 1.27+/pnpm 12+/bun 1.4+/dsh 0.2.x） |
| rg/tmux/age/fzf/vim/lf | 命令在 PATH 且版本非空 |
| ag/fd/bat/ncdu/btop/http/tldr/delta/lazygit/dust | M13 十件全在（fd→fdfind、bat→batcat 链接生效） |
| yq/hadolint/repo/magpie/caddy/filebrowser/ttyd/tailscale | 服务与工具二进制在且版本非空 |
| bats | 自身可执行（`bats --version`） |

### B2 服务运行/连通/登录（Given 容器服务全启 When 请求 Then 通）

| 用例 | 断言 |
|---|---|
| 六服务监听 | 22/3000/7681/8081/9090/8080 LISTEN |
| 鉴权闭环 | 无 Cookie GET / → 302 /login；POST /login（SERVICES.md 中的 dev 密码）→ 302 + Set-Cookie devbox_auth |
| 路由矩阵 | 带 Cookie：/ 200、/term/ 200、/file-share/ 200；/dsh/ 与 /magpie/ 非 503（ENABLE=1 时 302/200）；裸路径 /term 308 |
| filebrowser | 容器内 8081 /file-share/ 前缀健康（302/200） |
| magpie 网关 | 3425 GET /v1/models → 200 JSON；面板 3430 → 200 |
| SSH | 容器内 sshd 端口监听 + `ssh -o` 握手（宿主侧由 run-tests.sh 用 ssh 客户端探测 2222 可选） |

### B3 账号密码有效性（Given SERVICES.md 凭证 When 使用 Then 通过）

| 用例 | 断言 |
|---|---|
| dev 密码 | 从 /run/devbox/SERVICES.md 解析「dev / <pw>」→ auth-gate POST 登录 302（反向证明密码非占位/非 123 随机已生效） |
| root 密码 | 解析 root 行非空；`su -c` 形态不做（安全边界），以 dev sudo NOPASSWD 代替验证提权可用：`sudo -n true` |
| magpie key | SERVICES.md 解析 key → GET /magpie/?k=<key> 302/200（非 401 拦截页） |

### B4 动态文件真实可用（Given /run/devbox When 校验 Then 存在且内容可用）

| 文件 | 断言 |
|---|---|
| SERVICES.md | 存在、600 权限、含「登录凭证/服务入口/密钥与状态位置/升级与维护」四段 |
| dsh/url.txt | 存在、URL 形态 `http://<ip|host>:8080/dsh/?token=…`；**token 真实可用**：curl 带 auth cookie 兑换 → 303/200 |
| dsh/enabled、magpie/enabled | 存在（ENABLE=1） |
| cookie-secret | /var/lib/devbox/cookie-secret 存在且 32+ 字节 |
| tailscale state（ENABLE=1） | /var/lib/tailscale/tailscaled.state 存在；`tailscale status` Backends 状态非 Offline |

## 4. 通过标准

全部 @test PASS；任一 FAIL 输出 enough 上下文（实际值 vs 期望）供排障；run-tests.sh 退出码=失败数非零。
